# 绝区零 · 代理人立绘收集

本仓库收集《绝区零》（Zenless Zone Zero）所有代理人的立绘，按属性分类管理。

## 目录结构

```
zzz-illustrations/
├── {属性}/
│   └── {代理人名}.png
├── attr_map.json   # 代理人 → 属性映射表（来自 WIKI 筛选标签）
└── manifest.json
```

属性分类：电、火、冰、风、以太、烈霜、物理、玄墨、凛刃、流明。

> 注：「挽昼」为剧情角色，WIKI 未标注属性，归入「未知」。

## 数据来源

- 米游社绝区零 WIKI：https://baike.mihoyo.com/zzz/wiki/
- 代理人图鉴：https://baike.mihoyo.com/zzz/wiki/channel/map/2/43
- 属性标签来自 WIKI 内容列表 API（`home/content/list?channel_id=43`）中的 filter 标签。
