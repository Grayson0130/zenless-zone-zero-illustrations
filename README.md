# 绝区零 · 代理人立绘收集

本仓库收集《绝区零》（Zenless Zone Zero）所有代理人的立绘。

## 目录结构

```
zzz-illustrations/
├── {代理人名}.png
└── manifest.json
```

> 注：绝区零 WIKI（绳网情报站）未提供结构化的属性/阵营数据，因此暂按代理人名平铺管理；后续可按属性（物理/火/冰/电/以太）与专精进一步分类。

## 数据来源

- 米游社绝区零 WIKI：https://baike.mihoyo.com/zzz/wiki/
- 代理人图鉴：https://baike.mihoyo.com/zzz/wiki/channel/map/2/43
